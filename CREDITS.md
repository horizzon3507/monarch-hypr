# Credits

monarch-hypr builds on the work of others. The MIT license of each upstream applies to the code it contributed.

- [monarch-os/monarch](https://github.com/monarch-os/monarch): the base of this repository, including its full git history (author: y0no and contributors).
- [Omarchy](https://github.com/basecamp/omarchy): the original foundation of the installer, CLI and many commands, and the Hyprland-based design this fork moves back toward.
- [SkillArch](https://github.com/Orange-Cyberdefense/SkillArch) and Exegol: inspiration for the security tooling.
- [CachyOS](https://cachyos.org/) and Arch Linux: the distribution base and package ecosystem.
- [Hyprland](https://hyprland.org/) and the projects around it.

The upstream `LICENSE` file is kept unchanged.
